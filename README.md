# Forever Bloom Invitations

Create a modern premium wedding invitation website with an elegant luxury design.

Theme:

- Luxury Minimal

- Ivory, White, Gold, Champagne colors

- Glassmorphism effects

- Smooth animations

- Mobile-first responsive

- Romantic aesthetic

- Floral decorations with gold accents

- Premium typography

Landing Page:

When someone opens the shared link, display a beautiful animated splash screen with elegant particles and soft music or options to nasheeds .

Display:

"Together with their families"

Bride Name ❤️ Groom Name

with a fade-in animation.

Below show

"We invite you to celebrate our wedding."

Add a countdown timer until the wedding.
